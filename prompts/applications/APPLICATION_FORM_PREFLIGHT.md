# Application Form Preflight

## Copy/paste prompt

Inspect the actual application form/instructions for **{{ROLE}}** before expensive tailoring where practical. Record cover/motivation letter, short answers, salary, work authorization/sponsorship, relocation, travel, years of experience, legal/export/conflict attestations, demographic/voluntary fields, assessments, transcripts, references, portfolio/work samples, mandatory uploads, file/character limits, deadline, and duplicate/cooldown rules.

For each item use REQUIRED, OPTIONAL, NOT_FOUND, or UNKNOWN. Never invent legal, authorization, salary, or other consequential answers. Mark unresolved consequential questions `NEEDS_HUMAN_ANSWER` and stop only if they block safe preparation or submission.
