# Internal Prompt Library

These prompts are retained as **internal/reference material** for the coordinator and specialized workflows. A normal candidate should not browse or manually select from this library.

Friend-facing entry points are limited to four files in `user_actions/`:

1. `START.md`
2. `FIND_OPPORTUNITIES.md`
3. `BUILD_APPLICATIONS.md`
4. `RECORD_UPDATE.md`

After onboarding, natural-language requests should normally be enough. Interview and networking work should route automatically from ordinary requests.
