# Cross-Batch Audit

## Copy/paste prompt

Audit this completed set of **{{N}}** applications as a workflow cohort. Compare objective observations: execution mode, reviewer unique/duplicate findings, finding dispositions, human corrections, semantic rework, artifact iterations, QA/preflight defects, letter/networking decisions, process progression, and outcomes where known.

Label conclusions SUPPORTED, SUGGESTIVE, or UNKNOWN. Do not infer why an employer rejected/advanced someone from one outcome. Separate candidate-specific, domain-specific, and portable-system lessons. For any proposed rule change, write a learning proposal with alternative explanations, `does_not_mean`, validation needed, and a human approval gate.

## Cross-application overlap rule

Do not flag repeated evidence, bullets, projects, profile structure, or skills merely because they appear in multiple applications. Repetition is acceptable when the material remains the strongest supported choice for each exact JD. Flag repetition only when it exposes lazy/non-targeted composition, stale company/role text, a better evidence choice being ignored, or unsupported keyword reuse. Artificial differentiation is not an objective.
