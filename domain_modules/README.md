# Domain Modules

Domain modules customize the stable Career OS core without rewriting it. A module may define common evidence types, resume/CV conventions, work samples/portfolio expectations, specialist-review focus, interview formats, terminology, certifications/licenses, and common overstatement risks.

A module is **guidance**, not factual authority. Exact JDs and the candidate's canonical evidence always control target-specific work. Modules may be combined when a role spans fields.

Starter examples:
- `business_operations.yaml`
- `marketing_customer.yaml`
- `engineering_technical.yaml`

Create additional modules for finance, consulting, healthcare, research, policy, design, education, nonprofit, sales, or other fields as needed.
