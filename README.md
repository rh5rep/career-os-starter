# CAREER SEARCH OS — FRIEND PILOT

A private, human-in-the-loop job-search workspace that helps you set up your career profile once, find opportunities, decide what is worth pursuing, build tailored applications, prepare for interviews, track real process changes, and learn from outcomes.

**Pilot status:** usable for a real friend test, but not a production V1.0 release.

## Start here

Create your own **private** copy from the [Career Search OS starter](https://github.com/rh5rep/career-os-starter), then read **`START_HERE.md`**. For your first session, use the single prompt in **`user_actions/START.md`**.

After setup, you can use normal language. You should not need to learn schemas, evidence IDs, reviewer roles, Skills, workflow manifests, or Git internals.

Examples:
- “Find jobs for me in Boston and NYC.”
- “Which of these are actually worth applying to?”
- “Build applications for the top three.”
- “I submitted these two today.”
- “I have an interview with Company X next week.”

The repository keeps the structured machinery behind those requests. You remain responsible for consequential decisions and external actions such as factual corrections, legal/work-authorization answers, final application submission, networking sends, and offer decisions.
