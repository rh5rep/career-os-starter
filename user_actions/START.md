# 1 — Start / Set Me Up

Copy and send this once when you begin:

> Set up my Career Search OS. Interview me in manageable rounds and maintain the repository for me; do not ask me to edit YAML, choose schemas, assign evidence IDs, or select internal Skills. First ask me to upload or point you to any existing resume/CV, LinkedIn export or profile information, cover-letter example, portfolio/work samples, certifications/licenses, transcript, and other career records I want to use. Also ask what resume/CV/letter templates I want to preserve, if any.
>
> Then build my profile conversationally across: identity/contact; education; employment history; responsibilities and accomplishments; factual metrics; contribution versus ownership; certifications/licenses; skills; work authorization/sponsorship; locations and relocation; remote/hybrid/onsite preferences; compensation constraints; industries and exclusions; company/work-environment preferences; lifestyle/commute constraints; role hypotheses; networking preferences; interview readiness; and availability.
>
> Ask only a manageable batch at a time. “I don’t know,” “I need to verify,” and “I think so but I’m not sure” are valid answers. Never turn uncertainty into a fact or infer work authorization, salary commitments, dates, ownership, metrics, or outcomes. Treat uploaded materials as sources to reconcile, not automatic truth.
>
> Create internal evidence IDs, structured files, template registration, and routine validation yourself. Use VERIFIED, SUPPORTED, HOLD, or UNKNOWN as appropriate. Before setup is complete, show me a plain-English profile summary, the important preferences/constraints, initial role hypotheses, registered document templates, and every material HOLD/UNKNOWN. Wait for my approval or corrections. Only after I approve should you finalize/update the canonical repository files and mark onboarding complete.
