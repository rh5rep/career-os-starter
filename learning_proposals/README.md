# Learning Proposals

Material workflow changes are proposed here; they are never auto-applied from one outcome.

A proposal should contain: proposal ID/date, confidence (`SUPPORTED`, `SUGGESTIVE`, `UNKNOWN`), observation, population/sample, evidence, alternative explanations, `does_not_mean`, proposed change, validation required, scope (`CANDIDATE_SPECIFIC`, `DOMAIN_SPECIFIC`, `PORTABLE_SYSTEM`), human approval status, and `automatic_skill_rewrite_allowed: false`.

Approved proposals still require implementation and regression checks before they become active system rules.
