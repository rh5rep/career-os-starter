# Skills Evidence

This is a **claim-permission view**, not a keyword wishlist.

For every skill likely to appear externally, record:

| Skill | Evidence IDs | Safe wording | Scope / boundary | Status |
|---|---|---|---|---|
| Example skill | EVIDENCE-EXAMPLE | “Used X to…” | Do not imply expert ownership unless supported. | UNKNOWN |

## Guidance

- Prefer demonstrated usage over self-rated proficiency labels.
- If “expert,” “advanced,” “fluent,” “led,” “owned,” or similar wording is not directly supported, do not use it.
- A course, project, side activity, and professional use may all be valid evidence, but keep their context distinct.
- Target keywords may help retrieval; they do not create evidence.
