# Workflow Issues

Use this directory to capture repeated or significant failures without silently changing the system.

Examples: search explosion/timeouts, stale JD use, evidence drift, bad summary/profile pattern, artifact QA defect, reviewer failure, same-company conflict, authorization problem, batch coordination issue, or closeout ambiguity.

Each issue records observation, reproducibility, scope (`CANDIDATE_SPECIFIC`, `DOMAIN_SPECIFIC`, `PORTABLE_SYSTEM`), severity, proposed change, status (`PENDING`, `APPROVED`, `REJECTED`, `NEEDS_MORE_EVIDENCE`), and validation needed. Only approved changes proceed to a Skill/schema/template/test update.
