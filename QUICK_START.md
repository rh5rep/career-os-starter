# Quick Start — First Session

### 1. Make your private repo
Follow `SETUP_GITHUB.md`. The simple path is entirely browser-based.

### 2. Start one conversation
Open `user_actions/START.md`, copy the single prompt, and send it.

### 3. Give the system what you already have
Upload any resume/CV, LinkedIn export or profile notes, cover-letter example, portfolio/work samples, certifications/licenses, transcripts, or career records you want it to reconcile.

### 4. Answer in rounds
The system asks about your current details, education, work history, accomplishments, metrics, skills, authorization, preferences, constraints, role ideas, networking comfort, and availability. “I don’t know” and “I need to verify” are valid answers.

### 5. Approve your profile
Before setup is complete, you receive a plain-English summary plus a short list of unresolved items. Correct it. When you approve it, the system writes the structured profile and runs validation.

### 6. Register your document format
Tell the system which existing resume template to preserve, plus any optional CV or letter template. If you do not have one yet, leave it unregistered; the system should not invent a universal design.

### 7. Use natural language from then on
Try:

> Find jobs for me in Boston and NYC.

Then:

> Which of these are actually worth applying to?

Then:

> Build applications for the top three.

After you actually submit:

> I submitted Company A and Company B today.

That is the intended pilot experience. You should not need the internal prompt library for normal use.
